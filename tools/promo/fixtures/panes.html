Panes, the tmux way

A pane is a page that shares the window. Split once and the docs sit next to the code review; split again and the dashboard joins them. Each pane keeps its own mode, its own scroll position and its own history.

The prefix does the work: ctrl+b v splits right, ctrl+b - splits down, ctrl+b h j k l moves between panes, and ctrl+b z zooms the current pane to the full window and back.

Why panes beat windows

Windows overlap, panes never do. A pane layout is a tree, so it survives a restart, and a workspace keeps its own layout while you are away in another.

Close a pane and its tab stays; zoom a pane and the others wait, exactly where you left them.
