Rollback drill, Q3

Once a quarter the person on call rolls back a harmless release on staging, with a timer running, using only the runbook. The goal is under ten minutes from the decision to a healthy service.

Steps

  1. Deploy the drill build to staging and confirm it is live.
  2. Start the timer and follow the runbook's "Rolling back" section word for word.
  3. Stop the timer when the error rate and latency are back to normal.
  4. Write down every step the runbook got wrong, and fix the runbook the same day.
