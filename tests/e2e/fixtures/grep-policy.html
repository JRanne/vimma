Security policy

Supported versions

Only the latest release gets security fixes; there are no release branches or backports.

Reporting a vulnerability

Please report privately, not in a public issue or pull request.

Include what you can: the commit, the Firefox version, steps to reproduce, and what an attacker gains.

What to expect

  • an acknowledgement within a week;
  • an assessment, and a fix or a plan, within 30 days;
  • credit in the advisory, unless you prefer not to be named;
  • a security advisory once the fix is released.

Security model

The security model lists, for each risky part, what it must never do and the tests that enforce each rule.
